# Remin Islam — Digital Marketer Portfolio

A responsive, dark/neon portfolio website built as a static HTML/CSS/JS site.

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Upload the files to the `reminislam896/Digital-Marketer` repository.
2. In GitHub: Settings → Pages.
3. Choose the main branch and `/root` folder.
4. Save.

## Assets
The `assets/` folder contains the three images supplied for the portfolio.
